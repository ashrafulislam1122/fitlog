# FitLog

FitLog is a modern dark-themed workout library built with Next.js. It helps users browse workouts, view detailed exercise information, create a daily workout plan, and save workouts for later.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Toastify
- LocalStorage
- REST API

## Key Features

1. Browse a complete workout library.
2. Sort workouts by duration, calories, and rating.
3. View detailed workout information and instructions.
4. Add workouts to today's plan with a maximum of five exercises.
5. Save workouts for later.
6. Track completed workouts.
7. Remove workouts from the plan or saved list.
8. Responsive design for mobile, tablet, and desktop.
9. Persistent workout data using LocalStorage.
10. Toast notifications for workout actions.

## Project Structure

- `/` — Workout Library
- `/workout/[id]` — Workout Details
- `/my-plan` — Today's Plan and Saved Workouts
